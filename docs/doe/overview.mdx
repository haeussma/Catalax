Before running an experiment it is worth asking how much it will teach you. `catalax.doe` answers that question for any Catalax model: given a candidate design (which initial conditions to prepare and when to sample), it computes how much the measurements are expected to shrink the uncertainty of each kinetic parameter. Comparing candidate lab protocols, or checking that every parameter is identifiable before spending time at the bench, needs nothing more than the model and its priors.

## What the module computes

### Fisher information in log parameters

A design is a set of experimental arms. Each arm fixes the initial conditions of the states and constants, and a list of sampling times. For the free parameters $\theta$ (all parameters with `constant=False`), `catalax.doe` computes the sensitivities of every observable state at every sampling time with respect to $\log \theta$. Working in log space makes the result dimensionless: a design's score does not change when $K_m$ is reported in mM instead of µM.

The sensitivities are whitened by the observation noise, $w = \frac{1}{\mathrm{sd}(y)} \frac{\partial y}{\partial \log \theta}$, and the Fisher information sums over arms, times and observable states:

$$
F(\theta) = \sum_{\text{arms}} \sum_{t} \sum_{\text{observables}} w\, w^\top
$$

Two noise models are provided. `Homoskedastic(sigma)` has a constant standard deviation. `Proportional(cv, floor)` has $\mathrm{sd}(y) = \sqrt{\text{floor}^2 + (\text{cv} \cdot y)^2}$, the usual model for HPLC-type assays whose error grows with the measured amount. Any object with `scale(prediction)` and `whiten(sensitivities, prediction)` methods works as a noise model.

### Posterior shrinkage and efficiency

With a prior covariance $\Sigma_0$ on $\log\theta$, the Laplace approximation of the posterior after the experiment is

$$
\Sigma_\text{post} = \left(F(\theta) + \Sigma_0^{-1}\right)^{-1}
$$

The **efficiency** of parameter $j$ is the fraction of its prior uncertainty the design removes:

$$
e_j = 1 - \frac{\mathrm{sd}_{\text{post},j}}{\mathrm{sd}_{\text{prior},j}}
$$

An efficiency of 0 means the design teaches nothing beyond the prior, 1 means the parameter is pinned exactly. Because $F$ depends on the unknown $\theta$, `evaluate_design` averages over draws from the prior. It reports the mean efficiency per parameter and the **maximin** efficiency, $\mathbb{E}_\theta[\min_j e_j]$, the expected efficiency of the worst-determined parameter. A good design leaves no parameter close to its prior, so maximin is the number to compare designs by.

## Usage

A design is an ordinary `Dataset` holding one initial-condition-only measurement per arm. The `time` argument of `add_initial` sets the sampling times.

```python
import jax
import catalax as ctx
import catalax.doe as cdoe
import catalax.mcmc as cmc

ctx.enable_x64()  # Fisher matrices are often too ill-conditioned for float32

model = ctx.Model(name="Michaelis-Menten")
model.add_state("s, p, e")
model.add_ode("s", "-kcat * e * s / (k_m + s)", observable=True)
model.add_ode("p", "kcat * e * s / (k_m + s)", observable=False)
model.add_ode("e", "0", observable=False)

model.parameters["kcat"].value = 10.0
model.parameters["kcat"].prior = cmc.priors.Uniform(low=5.0, high=20.0)
model.parameters["k_m"].value = 100.0
model.parameters["k_m"].prior = cmc.priors.Uniform(low=50.0, high=200.0)

times = [10.0, 40.0, 80.0, 150.0, 300.0]

low_only = ctx.Dataset.from_model(model)
low_only.add_initial(time=times, s=50.0, p=0.0, e=0.1)
low_only.add_initial(time=times, s=60.0, p=0.0, e=0.1)

spread = ctx.Dataset.from_model(model)
spread.add_initial(time=times, s=50.0, p=0.0, e=0.1)
spread.add_initial(time=times, s=400.0, p=0.0, e=0.1)

noise = cdoe.Proportional(cv=0.05, floor=0.5)
key = jax.random.PRNGKey(0)

for name, design in [("low only", low_only), ("spread", spread)]:
    report = cdoe.evaluate_design(model, design, noise, key=key)
    print(name, report.maximin, report.efficiency)
```

Use the same `key` for every candidate so they are scored on the same prior draws.

To look at the information at a single parameter vector, the model's current values, use `fisher_information`:

```python
info = cdoe.fisher_information(model, spread, noise)
info.matrix           # (n_free, n_free), rows and columns in info.parameter_order
info.parameter_order  # ['k_m', 'kcat'], alphabetical like get_parameter_order()
info.valid            # False if any simulation failed to solve
```

Parameters marked `constant=True` are left out of the matrix and enter the simulation at their `value`. Only states whose ODE is marked `observable=True` contribute measurements. Declare `observable` explicitly for every state.

### States and constants

Every initial condition in a design is a design variable, whether it belongs to a state or to a constant. `catalax.doe` makes no distinction between enzymes, substrates, products or any other species. A state is measured if and only if its ODE is `observable=True`, and it changes only as its rate says: `"0"` keeps it at its initial amount, and a term such as `"-k_inact * e"` adds a parameter the design informs like any other. A constant cannot change during the reaction. The two are interchangeable for a species that does not change: for the bi-substrate model, the Fisher matrices with the enzyme as a constant and as an unobservable zero-rate state agree to 1.2e-8.

## Optimising a design

`optimize_design` searches the initial conditions of `n_arms` experiments for the design with the highest expected maximin efficiency, and returns it as a `Dataset` ready for the lab. Continuing the Michaelis–Menten example:

```python
spec = {
    "s": (10.0, 1000.0),  # free: each arm picks its substrate inside the box
    "p": (0.0, 0.0),      # fixed: no product at the start
    "e": (0.1, 0.1),      # fixed: one enzyme concentration
}

result = cdoe.optimize_design(
    model,
    spec,
    noise,
    n_arms=2,
    times=times,
    key=jax.random.PRNGKey(1),
    n_draws=16,
)

for measurement in result.dataset.measurements:
    print(measurement.initial_conditions)
print(result.report.maximin, result.report.efficiency)
print(result.restart_scores)
```

The **spec** maps every state and constant of the model to a range `(low, high)`. There are no defaults: an initial condition the spec leaves out is an error, whether it belongs to an enzyme, a substrate or a product. `low == high` fixes that initial condition at `low` in every arm; `low < high` lets every arm choose its own value inside the box. The **sampling times** are fixed: every arm is sampled at `times`. Optimising them tends to specialise the design toward the prior median and to give up the tails of the prior.

The search runs `n_restarts` gradient ascents (Adam) from Latin-hypercube starts. Each ascent maximises a smoothed maximin over `n_draws` fixed prior draws, and the restarts are then ranked on the exact maximin over `n_rank_draws` separate draws. `result.report` scores the winner on a third set of draws, because the winner's score on the draws it was selected on is biased upwards. Restarts that fail to solve on any ranking draw are dropped, since averaging over only the draws that solved would reward a design for failing; if every restart fails, `optimize_design` raises and suggests narrowing the bounds, raising `max_steps` or using a stiff solver.

**`restart_scores`** is the maximin of every restart on the ranking draws. When they agree, the landscape has one basin and the restarts were insurance. When some fall well short, the landscape has several basins and the restarts were necessary. In that case raise `n_restarts` and check that the best score holds up with a different `key`. Use at least a few restarts; a single ascent can settle in a poor basin.

**Cost** is linear in the number of prior draws and in the number of restarts. One gradient step for a bi-substrate model (4 states, 4 arms × 9 times, CPU, float64):

| `n_draws` | per step | 8 restarts × 300 steps | 24 restarts × 600 steps |
|---|---|---|---|
| 16 | 27 ms | ~1 min | 6.4 min |
| 64 | 105 ms | ~4 min | 25 min |
| 256 | 499 ms | 20 min | 2 h |

Explore with 16 draws, and use more for the design you run in the lab.

## Closing the loop

After round 1 has been measured, fit it with `run_mcmc` and design round 2 against the posterior instead of the priors. Pass the posterior samples as `belief`. `evaluate_design` and `optimize_design` then draw $\theta$ from those samples, with a bootstrap resample, and use their full log-space covariance as $\Sigma_0$. The correlations round 1 left in place are kept, for example a ridge between $k_\text{cat}$ and an inhibition constant. **Efficiency is then relative to the belief:** it is the shrinkage beyond what round 1 already taught, not beyond the priors.

Until real data exists, round 1 can be simulated at the model's parameter values, with the same noise model the design was scored under. Continuing the Michaelis–Menten example:

```python
import numpyro.distributions as dist

def measure(design, key):
    """Simulates the design at the model's values and adds the design's noise."""
    config = ctx.SimulationConfig(t1=max(times))
    data = model.simulate(design, config, saveat=design.to_time_matrix())
    for meas in data.measurements:
        key, k = jax.random.split(key)
        y = meas.data["s"]
        meas.data["s"] = y + noise.scale(y) * jax.random.normal(k, y.shape)
    return data

mcmc_config = cmc.MCMCConfig(
    num_warmup=500,
    num_samples=250,
    num_chains=4,
    chain_method="parallel",
    likelihood=dist.Normal,
    noise_cv=0.1,  # HalfNormal scale of the fitted cv; covers the design's 0.05
    verbose=0,
)

data = measure(result.dataset, jax.random.PRNGKey(2))
fit_1 = cmc.run_mcmc(model, data, 0.5, mcmc_config)  # 0.5: the noise floor

round_2 = cdoe.optimize_design(
    model,
    spec,
    noise,
    n_arms=2,
    times=times,
    key=jax.random.PRNGKey(3),
    n_draws=16,
    belief=fit_1.get_samples(),
)
print(round_2.report.efficiency)  # shrinkage beyond what round 1 taught

for meas in measure(round_2.dataset, jax.random.PRNGKey(4)).measurements:
    data.add_measurement(meas)
fit_2 = cmc.run_mcmc(model, data, 0.5, mcmc_config)
```

With lab data, `data` is the measured `Dataset` instead, and nothing else changes. The simulated states that are not observable (`p` and `e` here) can stay in the data: `run_mcmc` fits the observable states only, and warns that the others are unused.

- **Refit all the data under the original priors.** Merge the rounds with `add_measurement` and fit once more. Do not turn the last posterior into the next prior: the posterior is only known through finite samples, and any prior fitted to them is an approximation that compounds over rounds.
- **Match the likelihood to the design's noise model.** `likelihood=dist.Normal` with `noise_cv` set gives the floor-plus-proportional noise of `Proportional`, with the floor's scale from `yerrs`. The default `SoftLaplace` would only rescale the information, but it should still match.
- **Parallel chains need the host count set before JAX starts.** Call `ctx.set_host_count(n)` at the very top of the script, before any JAX operation, and use `chain_method="parallel"`. Four chains of the bi-substrate model took 80 s in sequence and 30 s in parallel. Once JAX has started, the call has no effect.
- **`constant=True` parameters** are held at their `value` by `catalax.doe`, but `run_mcmc` still samples them from their priors. Their posterior samples are ignored by `belief`.
- **Simulated data cannot detect a wrong rate law.** The data come from the model being fitted, so the fit is always consistent with it. Checking the mechanism needs real data.
- **Rounds are not free.** In progress-doe, where this module was developed, greedy round-by-round designs lost to one joint design with the same total number of arms. The loop pays off when the prior turns out to be wrong, not by default.

### How far to trust the efficiency numbers

Every efficiency is a Laplace approximation. It was checked against NUTS posteriors of the bi-substrate model (enzyme as an unobservable state, `Proportional(0.05, 5)`, 6 time points, truth at the geometric midpoints of the priors). The noise was fixed at the truth in NUTS, and each cell gives the range over 3 noise seeds of the ratio of the Laplace posterior sd to the NUTS posterior sd, both in log space:

| prior | arms | $k_\text{cat}$ | $K_{i,u}$ | $K_{m,A}$ | $K_{m,B}$ |
|---|---|---|---|---|---|
| Uniform | 4 | 0.67–0.73 | 0.68–0.73 | 0.83–0.85 | 0.77–0.86 |
| Uniform | 16 (random) | 0.76–0.84 | 0.78–0.83 | 0.79–0.95 | 0.92–1.02 |
| LogNormal | 4 | 0.93–0.98 | 0.93–0.96 | 1.00–1.03 | 0.99–1.08 |
| LogNormal | 16 (random) | 0.92–1.00 | 0.94–0.98 | 0.92–1.06 | 1.04–1.10 |

The LogNormal prior was matched to each Uniform prior in the mean and variance of $\log\theta$. The posterior correlation of $\log k_\text{cat}$ and $\log K_{i,u}$ was −0.98 to −1.00 in every run, so the ridge is not what separates the rows. The prior is. A `LogNormal` prior is Gaussian in $\log\theta$, so the Laplace step uses it exactly, and the numbers hold to within about 10%. A `Uniform` prior has no curvature in $\log\theta$ inside its box, but the Laplace step replaces it with a Gaussian of the same log variance. That Gaussian has curvature the Uniform does not, so it adds prior precision that is not really there. The efficiencies are then **optimistic** wherever the prior still carries weight: the posterior sd came out 1.2–1.5× wider than predicted at 4 arms. The gap closes as the data come to dominate the prior, as at 16 arms. With a Uniform prior, rank designs by efficiency, but do not read the absolute numbers as promises until the design pins the parameters well below their prior width.

## Requirements on priors

`evaluate_design` draws the free parameters from their own `prior`, the same priors `run_mcmc` uses. Every free parameter needs one, and because the design is scored in log parameters the prior must only allow strictly positive values:

- `Uniform(low, high)` with `low > 0`: fine, and the common case
- `LogNormal`, `LogUniform`, and `TruncatedNormal` with `low > 0`: fine
- `Normal`, or `Uniform`/`TruncatedNormal` with `low <= 0`: rejected with an error naming the parameter

For `LogNormal` priors the prior variance of $\log\theta$ is exact; for all other priors it is estimated from 20,000 prior samples.

## Solver settings and failed simulations

Information needs accurate derivatives, so both functions default to tight solver tolerances (`rtol = atol = 1e-8`, `max_steps = 4096`). Pass `config=ctx.SimulationConfig(...)` to change them. A simulation that fails never produces NaN in the results: its points contribute nothing to the information, `Information.valid` is `False`, and `evaluate_design` averages only over the prior draws that solved (`DesignReport.n_valid`).
