# `catalax.dataset.measurement`

### `Measurement` <sup><a href="https://github.com/JR-1991/Catalax/blob/master/catalax/dataset/measurement.py#L34" target="_blank"><Icon icon="github" style="width: 14px; height: 14px;" /></a></sup>


A class representing a measurement dataset with state concentrations over time.

The Measurement class stores time series data for chemical states, including their
initial concentrations and concentration values at each time point. It provides
methods for data manipulation, conversion, visualization, and integration with
other data formats.

Key capabilities:
- Store and manage time series concentration data
- Convert data between different formats (JAX arrays, pandas, dictionaries)
- Visualize measurement data with optional model comparison
- Data augmentation with noise for simulation purposes
- Import/export from common scientific data formats

**Attributes:**
- `id`: Unique identifier for this measurement.
- `name`: Optional name for the measurement.
- `description`: Optional description of the measurement.
- `initial_conditions`: Initial concentrations keyed by state name.
- `data`: Time series data keyed by state name.
- `time`: Time points for the measurement data.
- `state`: List of state names present in the data (computed field).

- New Measurement with a single unified time axis and
- NaN-padded data arrays.

#### `augment` <sup><a href="https://github.com/JR-1991/Catalax/blob/master/catalax/dataset/measurement.py#L743" target="_blank"><Icon icon="github" style="width: 14px; height: 14px;" /></a></sup>

```python
augment(self, sigma: float | None = None, seed: int = 42, multiplicative: bool = False, noise: NoiseModel | None = None) -> 'Measurement'
```

Create a new Measurement with noise-augmented data.

Every species gets its own independent Gaussian noise; the same ``seed``
reproduces it. Give either ``sigma`` (with ``multiplicative``) or ``noise``.

**Args:**
- `sigma`: Noise standard deviation. Additive\: ``y + N(0, sigma)``, in
data units, the same as ``noise=Homoskedastic(sigma)``. Multiplicative\:
``y * (1 + N(0, sigma))``, relative, ``Proportional(cv=sigma)`` without a floor.
- `seed`: Random seed for reproducibility.
- `multiplicative`: If True, ``sigma`` is relative rather than absolute.
- `noise`: Noise model with fixed values\: ``y + N(0, noise.scale(y))``.
Pass the same object to ``optimize`` or ``HMC.run`` to fit the noise you generated.

**Returns:**
- New Measurement object with noise-augmented data.

**Raises:**
- `ValueError`: If both ``sigma`` and ``noise`` (or neither) are given, or
``noise`` holds priors.
